# Required image assets

`pubspec.yaml` declares three asset directories under `assets/images/`. The
directories are tracked in git with a `.gitkeep` placeholder, but the real
image files live on the developer's machine and **must be copied in and
committed** before the app will render correctly. `flutter build` succeeds
with empty directories, but every `Image.asset` / `AssetImage` call below will
throw at runtime until the files exist.

Generated from `grep -rn "assets/images/" lib/` (see the "Referenced in"
column). Regenerate this list after adding new images.
