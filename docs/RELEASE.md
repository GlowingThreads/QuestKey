# Building a Play Store release of Quest Key

This covers the Android release build only (the project has no iOS target).
Signing keys are **never** committed: `android/key.properties`, `*.jks` and
`*.keystore` are git-ignored.

## 1. One-time: create the upload keystore

Run this once on the developer's machine (from the Flutter docs,
<https://docs.flutter.dev/deployment/android#signing-the-app>):

macOS / Linux:

```sh
keytool -genkey -v -keystore ~/upload-keystore.jks -keyalg RSA \
        -keysize 2048 -validity 10000 -alias upload
```

Windows (PowerShell):

```powershell
keytool -genkey -v -keystore $env:USERPROFILE\upload-keystore.jks `
        -storetype JKS -keyalg RSA -keysize 2048 -validity 10000 `
        -alias upload
```

`keytool` ships with the JDK bundled in Android Studio
(`<Android Studio>/jbr/bin`). Answer the prompts, choose strong passwords and
**back the `.jks` file up somewhere safe**: with Play App Signing enabled
(the default for new apps) Google holds the app-signing key, but you still
need this *upload* key for every future upload. Losing it means a key-reset
request through Play support.

## 2. Create `android/key.properties`

Create the file `android/key.properties` (next to `android/build.gradle.kts`)
with:

```properties
storePassword=<password from step 1>
keyPassword=<password from step 1>
keyAlias=upload
storeFile=/Users/<you>/upload-keystore.jks
```

`storeFile` is an absolute path (on Windows use forward slashes or escaped
backslashes, e.g. `C:/Users/you/upload-keystore.jks`). The file is already
listed in `.gitignore` and `android/.gitignore`; confirm with
`git status` that it is not staged.

`android/app/build.gradle.kts` reads this file. If it is missing the release
build prints a warning and signs with the debug key, so a fresh clone still
builds but the result **cannot be uploaded to Play**.

## 3. Bump the version

In `pubspec.yaml`:

```yaml
version: 1.0.0+1
```

`1.0.0` becomes `versionName`; the `+1` becomes `versionCode` and must be
strictly greater than the last uploaded build. The Gradle file reads both
from the Flutter plugin (`flutter.versionCode` / `flutter.versionName`); do
not hard-code them in Gradle.

## 4. Build

Make sure the image assets are in place (`assets/REQUIRED_ASSETS.md`) and the
launcher icon has been generated (`assets/icon/README.md`). Then:

```sh
flutter clean
flutter pub get
flutter build appbundle --release
```

Output: `build/app/outputs/bundle/release/app-release.aab`. This is the file
to upload to the Play Console (Internal testing → Create new release).

To sanity-check on a device first, build and install an APK:

```sh
flutter build apk --release
flutter install --release      # or: adb install build/app/outputs/flutter-apk/app-release.apk
```

Release builds have R8 minification and resource shrinking enabled. After
installing, **launch the app, create a hero and a quest, kill it from
Recents and relaunch**: the data must persist and there must be no crash.
An R8 crash on startup or a reminder that never shows means a keep rule is
missing; see `android/app/proguard-rules.pro` and
`android/app/src/main/res/raw/keep.xml`.

## 5. Upload

1. Play Console → your app → Testing → Internal testing → Create new release.
2. Upload `app-release.aab`. If this is the first upload, accept Play App
   Signing when prompted.
3. Fill in release notes, review, and roll out to the internal testers list.
4. Complete everything in `docs/PLAY_STORE_CHECKLIST.md` before promoting to
   production.

## Toolchain notes

- The Android project was generated by Flutter 3.29.x (AGP 8.7.0, Gradle
  8.10.2, Kotlin 1.8.22). `compileSdk`/`targetSdk` are 36 to satisfy Google
  Play's 31 Aug 2026 target-API requirement; AGP 8.7 was only *tested* up to
  35, so `android.suppressUnsupportedCompileSdk=36` silences its advisory in
  `android/gradle.properties`. When you next upgrade Flutter, take the
  template's newer AGP/Gradle/Kotlin versions and remove that property.
- `minSdk` is 21: the minimum for `flutter_local_notifications` and
  `flutter_timezone`, and Flutter's own floor.
- Java 17 is required by AGP 8.x. Android Studio's bundled JDK works:
  `flutter config --jdk-dir "<Android Studio>/jbr"`.
